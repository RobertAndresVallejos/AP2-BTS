Mémento commandes Linux

Commande Description Exemple d'utilisation
ls Liste les fichiers et dossiers ls -l
cd Change de répertoire cd /home/user
touch Crée un fichier vide touch mon_fichier.txt
mkdir Crée un nouveau dossier (répertoire). mkdir mon_dossier
cat Crée un fichier et permet d'écrire directement dedans (utilisez Ctrl + D pour enregistrer et quitter). cat mon_fichier.txt
cp Copie un fichier. cp document.txt copie_document.txt
mv Déplace ou renomme un fichier/dossier. mv document.txt ~/Documents/
mv ancien_nom.txt nouveau_nom.txt
rmdir Supprimer un dossier vide rmdir mon_vide
rm Supprimer un dossier + sous - dossiers rm -r mon_dossier_plein
